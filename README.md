# Particle Life

色ごとに決めた「引き合う／反発する」ルールだけで、粒子が生き物のように集まったり追いかけ合ったりするシミュレーションです。

`index.html` 1つだけで動きます。外部ライブラリは使っていません。ブラウザで開くとすぐに始まります。

## 動かし方

`index.html` をブラウザで開きます。PC・スマホ・iPad のどれでも動きます。

## 主な機能

- **ルール**: 色の数（1〜12）× 色の数の相互作用行列で決まります。行列の値は、ランダムに作り直すことも手で編集することもできます。
- **ゆらぎ**: 行列の値がなめらかに少しずつ変化し続けます。変化の大きさは調整できます。
- **配色**: 虹、パステル、ネオン、暖色、寒色、森と大地、夕焼け、白黒の8種類です。
- **形**: 粒子を四角と円で切り替えられます。
- **表示**: 表示位置の移動、ズーム（100〜800%）、全画面表示ができます。
- **画面の端**: 上下・左右の端がつながっていて、出ていった粒子は反対側から戻ってきます。

## 操作

| 操作 | PC | スマホ・iPad |
|---|---|---|
| 表示移動 | ドラッグ / 矢印キー | 1本指ドラッグ |
| ズーム | ホイール / `+` `−` | 2本指ピンチ |
| 行列の値 +0.2 | 左クリック | タップ |
| 行列の値 −0.2 | 右クリック | 長押し |
| 行列の値 ±0.05 | ホイール | ― |
| 一時停止 | `Space` | ボタン |
| 新ルール | `R` | ボタン |
| ゆらぎ 開始 / 停止 | `D` | ボタン |
| 配色 次 / 前 | `G` / `Shift+G` | メニュー |
| 形 四角 / 円 | `O` | ボタン |
| 表示リセット | `C` | ボタン |
| 全画面 | `F` | ボタン（対応端末のみ） |
| パネル 表示 / 非表示 | `H` | ● / ○ ボタン |

## しくみ

- **力の計算**: 距離が近すぎると反発します。少し離れた距離では、行列の値に応じて引き合うか反発します。作用半径より遠い粒子からは力を受けません。
- **計算を速くする工夫**: 画面を作用半径の大きさのマスに分けて、周囲9マスの粒子とだけ計算します。粒子は毎フレームマスの順に並べ直し、メモリを読む効率も上げています。
- **描画**: WebGL で、粒子を点として GPU に描かせます。WebGL が使えない環境では Canvas 2D で描きます。
